To enable Data Suite to display your actual data on reports, you need to provide raw data by uploading Excel/CSV files.

1. For each raw table in the list, download the sample Excel file to view its corresponding structure.
2. Fill in data into the sample file, keeping the structure intact (column names and number of columns).
3. Upload the completed Excel/CSV file to the corresponding raw table.
4. Once all raw tables have been uploaded with data, click "Run Pipeline" to run the initial ETL process.
