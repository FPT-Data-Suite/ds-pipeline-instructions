Để Data Suite hiển thị dữ liệu thực tế trên báo cáo, bạn cần cung cấp dữ liệu thô bằng cách upload file Excel/CSV.

1. Với mỗi table raw trong danh sách, tải file Excel mẫu để xem cấu trúc tương ứng.
2. Điền dữ liệu vào file mẫu, giữ nguyên cấu trúc (tên cột và số lượng cột).
3. Upload file Excel/CSV đã có dữ liệu lên table raw tương ứng.
4. Sau khi upload đủ dữ liệu cho tất cả table raw, nhấn "Kích hoạt Pipeline" để chạy ETL lần đầu.
